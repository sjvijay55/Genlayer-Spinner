# Genlayer-Spinner
Animated loading spinner built with pure CSS + inline SVG using the GenLayer logo mark. Features rotating arc ring, dual orbit dots, and pulsing center logo. Light/dark mode auto-switch. Three sizes: 32px, 52px, 80px. Zero dependencies, drop-in ready.
# GenLayer Spinner

Animated loading spinner for the GenLayer Portal.

## Preview
Open `genlayer-spinner.html` in any browser.

## Usage
Copy the `.gl-spinner` block + CSS into your project. No dependencies.

## Sizes
- `.gl-spinner.sm` — 32px
- `.gl-spinner.md` — 52px  
- `.gl-spinner.lg` — 80px

## Features
- Pure CSS + SVG, zero JS
- Light & dark mode automatic
- Infinite smooth loop
- GenLayer logo identity
